Run on the robot

    
Uses the selected retargeted finger angles and palm motion, with arm IK and slower timing for physical replay. MuJoCo simulation motion is never used. Preparation is offline; physical execution requires your confirmation.

    
    
Preparation filters jitter and allocates time locally under arm and finger planning limits. New plans must fit an eight-second budget including final settling. Arm and hand move together continuously through the waypoints; the resulting path is checked again. New rollouts start at the current measured pose and translate the Cartesian hand path to it, then solve arm IK again. Run rechecks the shifted path before sending commands.

    
    
    
Applied to both arm and fingers. Slower requests may exceed the eight-second budget and be refused. Prepare again after changing it.
